1. Executive Summary

Production Architecture Baseline (MapLibre Native + In-Memory H3 Index + Official Barikoi Weights)
The headline commercial monthly API bill on Barikoi Business is ৳1.65M BDT ($15,013 USD), NOT ৳23.9M.
• Barikoi Official Call Weighting: Per Barikoi's official pricing guide (docs.barikoi.com/pricing/pricing-call), a single Routing API request counts as 2 API calls (and Map API tile requests count as 4 calls). Platform HTTP requests total 15,303,690 requests/month (~15.30M), which translate to 27,690,480 Barikoi billable calls.
• Shop Route Batching Correction: 2,000 daily shop deliveries are grouped into 800 batched routes (2.5 stops/route). Drivers navigate 800 routes, eliminating 3.25M overcounted phantom navigation calls.
• MapLibre Native GPU Caching (0 Continuous Tile Calls): Vector tiles (.pbf) are cached in SQLite on-device; 10s driver GPS pings are coordinate-only WebSocket messages, not HTTP tile requests.
• Server-Side In-Memory H3 Dispatch: Driver search uses Uber H3 hexagonal indexing (utils-server/h3Index.ts), eliminating external Distance Matrix API calls for ride-hailing and food delivery.
• Codebase Fallback Reality: In lib/barikoi.ts, failure fallback routes to Google Directions (Dingi is NOT wired in code). A 5% failover to Google adds ~৳340K/month, making internal circuit breakers critical.

Provider Verdict:

  • Cheapest Commercial Plan: Barikoi (Business Plan) is the most economical commercial tier under Barikoi's official pricing (barikoimaps.com/pricing). Priced at ৳50,000/month (includes 1,000,000 calls) with an overage rate of BDT 0.060 / call (৳60 / 1,000 calls), total monthly cost on 27.69M billable calls is ৳1,651,429/month ($15,013 USD)—an effective cost of ৳2.20 per completed order.
  • Business Beats Scale by ৳365,357/month: Barikoi's Business Plan (৳50K base + ৳0.060/call) beats the Scale Plan (৳90K base + ৳0.075/call at ৳2,016,786/mo). Although Scale includes 1M more base calls, its 1.5 paisa higher overage rate costs ৳385K more across the remaining 25.69M overage calls, resulting in a net monthly penalty of ৳365K.
  • The Engineering Sweet Spot (Self-Hosted OSRM Hybrid): Routing accounts for 12.39M requests/month (24.77M Barikoi billable calls). Deploying a self-hosted OSRM routing engine on a $40/month cloud VPS (৳4,400 BDT) for courier turn-by-turn navigation while routing address search and geocoding to Barikoi (2.92M calls) drops total monthly spend to ৳169,414/month ($1,540 USD)—only ৳0.23 per completed order (saving 89.7% / ৳1.48M/month)!
  • Lean Production Architecture Alternative (Quote-Time Routing): In Ride's actual codebase, routes are fetched at quote/request time, not continuously polled during driver transit (~3 route calls/trip). If modeled as quote-time routing, Barikoi Business spend drops to only ৳435,014/month ($3,955 USD)—only ৳0.58 per completed order!
  • Google Maps Platform (Mobile Native SDK Reality): With Google Maps Mobile SDKs, map tile display is $0.00. However, Directions ($5.00/1K), Geocoding ($5.00/1K), and Autocomplete ($2.83/1K) still cost $73,101 USD / month (~৳8.04M BDT)—which is 4.9× more expensive than Barikoi Business.
  • Dingi: Costs ৳1.46M/month ($13,308 USD) under 100K+ tiered pricing. Note: Dingi is an external market benchmark and is not currently integrated in the Ride repository.

4.0 Operational Baseline Assumptions (Fleet & Entity Sizing)

To ground the 25,000 daily order volume in operational reality, the platform models the following entity sizing:

  • Ride-Hailing (15,000 completed rides/day — Blended Operations):
    • Active Vehicles / Drivers on Shift: ~1,986 to 2,143 drivers active on the road daily.
    • Blended Driver Utilization: 7.0 to 7.55 completed rides per active driver per day (~15,000 rides).
    • Active Unique Riders: ~12,500 active riders daily (averaging ~1.2 rides per active rider per day; ~80% single-trip riders, ~20% round-trip commute riders).
    • Registered Fleet Pool: ~3,000 to 3,200 registered drivers (assuming a standard ~65–67% daily shift participation rate).
  • Food Delivery (8,000 orders/day):
    • Active Partner Restaurants: 727 restaurant partner outlets active and taking orders daily.
    • Restaurant Order Velocity: 11.0 orders per restaurant per day (727 × 11.0 ≈ 7,997 orders).
    • Active Delivery Couriers: ~889 active motorcycle/bicycle couriers (averaging 9.0 deliveries per courier per shift).
  • Shop Delivery (2,000 orders/day):
    • Active Merchant Shops / Distribution Hubs: 167 e-commerce warehouses and retail pickup points.
    • Dispatches per Merchant: 12.0 dispatches per hub per day (167 × 12.0 ≈ 2,004 packages).
    • Batched Delivery Routes: 800 delivery routes dispatched daily, averaging 2.5 customer stops per batched trip.

10. Final Recommendation

Primary Commercial Recommendation: Barikoi (Business Plan) + OSRM Hybrid

Standardize on Barikoi on the Business Plan (৳50,000 base for 1,000,000 calls + BDT 0.060 / call overage). Under production volume (15.30M requests / 27.69M billable calls with 2× routing weight), Barikoi Business costs ৳1,651,429/month ($15,013 USD), which is ৳365,357/month cheaper than Barikoi Scale. For maximum profitability, deploy a Self-Hosted OSRM container ($40/mo VPS) for courier routing recalcs, dropping total platform map spend to ৳169,414/month ($1,540 USD)—only ৳0.23 per completed order! Combined with local VAT-deductible BDT invoicing and superior Bangladesh address accuracy, Barikoi is the clear commercial winner.

Secondary / Fallback Provider: Google Maps (Circuit-Breaker Protected)

In Ride's actual codebase (lib/barikoi.ts), the failure fallback is googleRoute (Google Directions). Critical Warning: A 5% failover rate to Google Directions at $5.00/1K will generate ~৳340,637 BDT / month ($3,097 USD) in GCP bills. Google failover must be strictly throttled with a circuit breaker, with Haversine × 1.3 as the default low-cost fallback.

Never Use as Primary: Google Maps Platform

At $73,101 USD / month (~৳8.04 million BDT), Google Maps is 4.9× more expensive than Barikoi Business and 47× more expensive than the OSRM Hybrid. Furthermore, corporate credit card quota limits in Bangladesh make remitting ~$73K USD/month impossible without special central bank approval. Google Maps should exist solely as an emergency fallback.

Appendix: Sensitivity Notes

Mandatory Parameter Context (Prompt Guideline)

Per prompt instructions: "If a value seems unrealistic, note it in a 'Sensitivity Notes' section, but do not change it without permission." Below are the critical technical discrepancies between the fixed parameter model and actual production mobile engineering:

  1. Barikoi Official Call Weighting (docs.barikoi.com/pricing/pricing-call): Barikoi bills calls, not HTTP requests. The Routing API consumes 2 calls per request, and the Map API (Tiles) consumes 4 calls per request. On 12.39M routing requests, Barikoi bills 24.77M calls, increasing the monthly Business bill to ৳1.65M.
  2. The 300M Tile Render Assumption vs Mobile SDK Architecture: In production mobile engineering (using MapLibre Native in Ride), vector tiles (.pbf) are rendered locally on-device by the GPU. A GPS heartbeat merely moves a marker coordinate; it does NOT hit an HTTP tile server. MapLibre's local SQLite disk cache absorbs >85% of movement. To eliminate Barikoi tile costs completely (which Barikoi counts as 4 calls/req), Ride can point style.json to open OSM vector tiles or a self-hosted Cloudflare R2 vector tile cache.
  3. Google Maps Mobile SDK Pricing Reality: Under official Google Maps Platform terms, Dynamic Maps on native mobile (Maps SDK for Android & Maps SDK for iOS) is $0.00 (Unlimited Free Usage). On native mobile apps, Google's total bill is $73,101 USD / month (~৳8.04 million BDT) for server-side directions, geocoding, and autocomplete.
  4. In-Memory H3 Geo-Indexing vs External Distance Matrix: In Ride's actual codebase (utils-server/h3Index.ts), driver proximity is resolved entirely in memory using Uber H3 hexagonal indexing. Zero external Distance Matrix API calls are made during dispatch, saving ৳28,350/month on Barikoi Business and $2,363/month on Google.
  5. Lean Production Architecture Alternative (Quote-Time Routing): In real-world ride-hailing and food delivery, turn-by-turn navigation is rendered client-side on the driver's device (or handed off to Google Maps/Waze via intent). The backend only fetches routes at quote creation and significant off-corridor deviations (~3 route requests per order). Under this lean model, total Barikoi calls drop to 7,416,900 calls/month, bringing the Barikoi Business bill down to only ৳435,014 / month ($3,955 USD / ৳0.58 per order).
  6. Fallback Provider in Code: The codebase (lib/barikoi.ts) implements Google Directions as fallback, not Dingi. If 5% of route calls fail over to Google, that failover costs ~৳340,637/month. Dingi is not built into the repository.
