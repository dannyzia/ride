D-131 · Settings module: driver-settings
FieldContent
IDD-131
nameSettings
moduledriver-settings
PurposeCentral hub listing all driver preferences, account, support and legal destinations; entrance to the settings subtree.
Entry / exitEntry: from driver home / profile (router.push to this route). Exit: Back button (router.back) returns to previous screen; list rows router.push to sub-screens.
UI elementsHeader with chevron-back + "Settings" title. ThemeToggle component at top. Grouped section lists: Subscription (Packages, Minimum Rate, Payout Method), Preferences (Notifications, Auto-Accept, App Appearance, Language), Account (Account & Security), Support (Lost Items, Support, Safety, Referral), Legal (Terms of Service, Privacy Policy). Each row = icon + label + chevron-forward.
StatesNo distinct loading/empty/error states — static list rendered from a constant array. Dark/light handled via useIsDark.
ActionsTap "Settings" back (chevron-back) → router.back(). Tap ThemeToggle → toggles app theme. Tap any row → router.push to its route (e.g. /(main)/(rider)/settings/notifications).
Data shownStatic labels, icons (Ionicons glyph names) and section names hard-coded in SETTINGS array. No remote data.

D-132 · Account & Security module: driver-settings
FieldContent
IDD-132
nameAccount & Security
moduledriver-settings
PurposeShows account security summary and provides sign-out and account-deletion actions.
Entry / exitEntry: from D-131 Settings (Account & Security row). Exit: Back → router.back(); "Security & Login Info" → router.push change-password; Sign out / Delete open confirm modals (D-133 / D-134).
UI elementsHeader: "Back" + "Account & Security" title. Card "Security & Login Info" (subtitle: Phone number & login method). Card "Two-factor authentication" (subtitle: Not configured). Card "Sign out" (subtitle: Disconnect and return to the login screen). Card "Delete account" (red text; subtitle: Permanently remove your account and all data). Floating theme-toggle button top-right.
StatesDefault static cards. 2FA card always shows "Not configured". error text rendered inside the delete modal (D-134) only.
ActionsTap Back → router.back(). Tap "Security & Login Info" → router.push("/(main)/(rider)/settings/change-password"). Tap "Sign out" → opens Sign Out modal (D-133). Tap "Delete account" → opens Delete Account modal (D-134). Floating theme button → toggles light/dark.
Data shownStatic labels. No remote data fetched on this screen. 2FA status is hard-coded "Not configured".
