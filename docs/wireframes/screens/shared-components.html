Ride — Shared UI Components

Total Components: 32
What exists The Ride project has a flat components/ directory with shared building blocks used across rider, driver, and admin screens. Key modules: components/ (root shared), components/admin/ (admin-panel primitives), components/auth/ (auth guards). Components are PascalCase .tsx files. All use the goRide theme tokens and support dark mode via useIsDark(). No third-party UI kit — all components are hand-built with React Native primitives.
