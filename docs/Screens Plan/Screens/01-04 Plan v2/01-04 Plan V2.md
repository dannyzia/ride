    84	## 2. Design Philosophy — Bangladesh Futuristic
    85	
    86	The future of mobility, designed for real Bangladesh.
    87	
    88	Futuristic does NOT mean dark backgrounds + neon. It means:
    89	- Information architecture precision
    90	- Typography hierarchy
    91	- Motion that communicates state
    92	- Spatial hierarchy
    93	- Intelligent status indicators
    94	- Subtle depth
    95	- High-quality iconography
    96	- Real-time information
    97	
    98	### 2.1 Bangladesh-First Constraints
    99	
   100	| Constraint | Design Response |
   101	|------------|-----------------|
   102	| Strong sunlight / outdoor use | Light-first default. High contrast. No subtle grays. |
   103	| Cheap Android devices | Minimal blur, limited shadows, efficient animations, memoized components |
   104	| Fingerprints / glare on screens | Large touch targets (min 48dp). Crisp borders. No tiny text. |
   105	| Inconsistent connectivity | Graceful degradation. Retry buttons. Offline state indicators. |
   106	| GPS accuracy variations | Fallback to manual address entry. Clear "location unavailable" states. |
   107	| Drivers on motorcycles | Glanceable UI. Large buttons. Minimal cognitive load. |
   108	| Low-end GPUs | No complex gradients. Simple vector assets. Limited Reanimated worklets. |
   109

   137	### 2.3 Rider vs Driver Design Split
   138	
   139	| Aspect | Rider | Driver |
   140	|--------|-------|--------|
   141	| Visual density | Expressive, refined | Functional, sparse |
   142	| Animation | Rich transitions | Minimal, purposeful |
   143	| Touch targets | Standard 48dp | Larger 56dp minimum |

   151	## 3. Theme System (Pattern A — Mandatory)
   152	
   153	### 3.1 Hook Usage
   154	
   155	```tsx
   156	import { useIsDark } from "@/lib/useAppearance";
   157	
   158	const isDark = useIsDark();
   159	
   160	const bg = isDark ? colors.bgDark : colors.bgLight;
   161	const surfaceBg = isDark ? colors.surfaceElevatedDark : colors.surfaceLight;
   162	const borderColor = isDark ? colors.borderDark : colors.borderLight;
   163	const textPrimary = isDark ? colors.textPrimaryDark : colors.textPrimaryLight;
   164	const textSecondary = isDark ? colors.textSecondaryDark : colors.textSecondaryLight;
   165	const textDisabled = isDark ? colors.textDisabledDark : colors.textDisabledLight;
   166	```
   167	
   168	**NEVER write `theme === "dark"` or `theme === "dark" || theme === "system"` in any screen.**
   169	
   170	### 3.2 StatusBar Pattern
   171	
   172	```tsx
   173	<StatusBar barStyle={isDark ? "light-content" : "dark-content"} backgroundColor={bg} />
   174	```
   175	
   176	Every screen owns its own StatusBar.
   177	
   178	### 3.3 Theme Toggle Pattern
   179	
   180	- **Auth screens:** `<AuthLayout showThemeToggle>`
   181	- **Main screens:** Absolute top-right `TouchableOpacity` with Ionicons sun/moon icon, 40x40dp, `surfaceBg` + `borderColor` border.
   182	
   183	```tsx
   184	<TouchableOpacity
   185	  onPress={() => setTheme(isDark ? "light" : "dark")}
   186	  style={{
   187	    position: "absolute", top: 16, right: 16, zIndex: 10,
   188	    width: 40, height: 40, borderRadius: 20,
   189	    backgroundColor: surfaceBg, borderWidth: 1, borderColor,
   190	    alignItems: "center", justifyContent: "center",
   191	  }}
   192	  hitSlop={{ top: 8, bottom: 8, left: 8, right: 8 }}
   193	>
   194	  <Ionicons name={isDark ? "sunny-outline" : "moon-outline"} size={20} color={textPrimary} />
   195	</TouchableOpacity>
   196	```

   201	
   202	### 4.1 Font Family
   203	
   204	Plus Jakarta Sans (already in `assets/fonts/`):
   205	- **Jakarta-Bold** — Screen titles, CTAs, prices
   206	- **Jakarta-SemiBold** — Section headers, button text
   207	- **Jakarta-Medium** — Body text, labels
   208	- **Jakarta-Regular** — Captions, secondary text
   209	
   210	### 4.2 Typography Scale
   211	
   212	| Token | Rider | Driver | Weight | Use Case |
   213	|-------|-------|--------|--------|----------|
   214	| Display | 28px | 32px | Bold | Screen titles, greetings |
   215	| Heading | 18px | 22px | SemiBold | Section headers |
   216	| Body | 15px | 18px | Medium | Primary content, inputs |
   217	| Label | 13px | 14px | Regular | Captions, metadata |
   218	| Caption | 11px | 12px | Regular | Timestamps, micro-copy |
   219	| Metric | 36px | 40px | Bold | Prices, large stats |
   220	| ETA | 20px | 24px | Bold | Timers, countdowns |
   221	
   222	### 4.3 Touch Targets
   223	
   224	- **Rider:** Minimum 48x48dp
   225	- **Driver:** Minimum 56x56dp
   226	- **Critical actions:** 64x64dp or full-width 56dp height
   227	
   228	### 4.4 Radius Scale
   229	
   230	- Cards: 16px
   231	- Inputs: 12px
   232	- Buttons: 12px
   233	- Avatars: 50% (circle)
   234	- Pills: 9999px (full rounded)

   812	  -> Deny/Skip -> SERVICES_HUB (do NOT block)
   813	NOTIFICATIONS_PERMISSION
   814	  -> Grant -> SERVICES_HUB
   815	  -> Skip -> SERVICES_HUB (do NOT block)
