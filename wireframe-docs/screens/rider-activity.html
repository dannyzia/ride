Activity Overview Screen Wireframe

Purpose

Overview of ride history with tabs for different ride statuses

Entry / Exit

Entry: Bottom tab navigation
Exit: Specific activity category screens

UI Elements

  • Tab bar: All, Upcoming, Completed, Canceled
  • List of ride cards grouped by date
  • Empty state illustration and message
  • Refresh indicator

States

default loading empty error

Actions

Tab selection - filters rides by status
Ride card tap - opens ride detail screen
Pull to refresh - reloads activity data

Data Shown

Ride date and time
Pickup and dropoff locations
Ride status icon and text
Fare amount
Vehicle type

Ride Detail Screen Wireframe

Purpose

Displays comprehensive details of a specific ride

Entry / Exit

Entry: Activity lists, notifications
Exit: Back to activity list

UI Elements

  • Ride header: date, time, status badge
  • Route summary with map preview
  • Fare breakdown section
  • Driver information card
  • Vehicle details
  • Timeline of ride events
  • Action buttons: Share, Rebook, Report issue

States

default loading error success

Actions

Share button - generates shareable ride summary
Rebook button - opens find ride with pre-filled locations
Report issue button - opens issue reporting flow
Timeline expansion - shows/hides detailed events

Data Shown

Exact pickup and dropoff timestamps
Actual route taken (map polyline)
Total distance and duration
Complete fare breakdown (base, waiting, tolls, etc.)
Driver name, rating, and photo
Vehicle type, license plate, color
Pickup and dropoff addresses (full)
Any applied promotions or discounts
Rating given to driver (if any)
