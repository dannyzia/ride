Phone Entry Screen Wireframe

Purpose

User enters their phone number to begin authentication process

Entry / Exit

Entry: App launch, deep link, logout
Exit: OTP Verify screen (on valid phone number)

UI Elements

  • Phone number input field with country selector
  • Primary button: "Send OTP"
  • Text: "We'll send a one-time password to verify your number"
  • Link: "Having trouble receiving the code?"

States

default loading error success

Actions

Phone number input - validates format
Country selector - opens country list modal
Send OTP button - navigates to OTP Verify screen
Help link - shows troubleshooting modal

Data Shown

Phone number (user input)
Country code (from selector)

OTP Verify Screen Wireframe

Purpose

User enters the OTP received via SMS to verify their phone number

Entry / Exit

Entry: Phone Entry screen
Exit: Register screen (new user) or Main app (existing user)

UI Elements

  • OTP input fields (typically 6 separate boxes)
  • Primary button: "Verify OTP"
  • Text: "We've sent a code to +880 XXX XXXXXX"
  • Link: "Resend OTP"
  • Link: "Edit phone number"

States

default loading error success

Actions

OTP input fields - auto-focus and validation
Verify OTP button - validates code and proceeds
Resend OTP - sends new OTP
Edit phone number - returns to Phone Entry screen

Data Shown

Phone number (masked)
OTP code (user input)

Register Screen Wireframe

Purpose

New user completes registration by providing additional profile information

Entry / Exit

Entry: OTP Verify screen
Exit: Main app home screen

UI Elements

  • Name input field
  • Email input field (optional)
  • Password input field (optional)
  • Primary button: "Complete Registration"
  • Text: "Almost done! Tell us a bit about yourself"

States

default loading error success

Actions

Name input - validates required field
Email input - validates format if provided
Password input - validates strength if provided
Complete Registration button - creates user account

Data Shown

Phone number (pre-filled, read-only)
Name (user input)
Email (user input, optional)
Password (user input, optional)
