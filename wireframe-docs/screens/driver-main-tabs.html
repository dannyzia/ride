Driver Home Screen Wireframe

Purpose

Main screen for drivers to see ride offers and manage availability

Entry / Exit

Entry: App launch, bottom tab navigation
Exit: Offer details, Profile, Earnings, etc.

UI Elements

  • Availability toggle switch (Online/Offline)
  • Current status and earnings today
  • Active ride offer card (when available)
  • Offer details: pickup→dropoff, vehicle type, fare estimate
  • Action buttons: Accept, Decline
  • Bottom navigation: Home, Active Subscription, Earnings, Profile
  • Heat map overlay showing demand areas

States

default loading empty error

Actions

Availability toggle - switches online/offline status
Offer card tap - expands to show full offer details
Accept button - accepts the ride offer
Decline button - declines the ride offer
Bottom tab navigation - switches between app sections

Data Shown

Driver's online/offline status
Today's earnings and rides completed
Active ride offer (when available)
Pickup and dropoff locations
Estimated fare and ETA
Required vehicle type
Distance to pickup
Heat map intensity (demand level)
