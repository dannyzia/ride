Profile Screen Wireframe

Purpose

User profile management and account settings

Entry / Exit

Entry: Bottom tab navigation
Exit: Edit profile, settings screens

UI Elements

  • User avatar/profile picture
  • Display name and phone number
  • Account status and verification badges
  • Quick stats: total rides, total spent, member since
  • Action buttons: Edit profile, Wallet, Settings
  • Logout button at bottom

States

default loading error success

Actions

Edit profile button - opens profile editing screen
Wallet button - opens wallet overview
Settings button - opens settings menu
Logout button - shows logout confirmation

Data Shown

User's display name
Phone number (masked)
Account creation date
Total amount spent on rides
Current wallet balance (if applicable)
Verification status (email, phone, ID)

Edit Profile Screen Wireframe

Purpose

Allows user to edit their profile information

Entry / Exit

Entry: Profile screen
Exit: Profile screen (with updated info)

UI Elements

  • Avatar upload/tap to change
  • Name input field
  • Phone number display (usually read-only)
  • Email input field
  • Date of birth input
  • Gender selection
  • Primary button: "Save Changes"
  • Cancel button

States

default loading error success

Actions

Avatar tap - opens image picker/camera
Name input - validates and saves
Email input - validates format
Date of birth input - age validation
Gender selection - updates preference
Save Changes button - validates and saves profile
Cancel button - discards changes

Data Shown

Current avatar/image
Current name
Phone number (read-only)
Current email (if set)
Current date of birth (if set)
Current gender setting

Wallet Overview Screen Wireframe

Purpose

Displays wallet balance, transaction history, and top-up options

Entry / Exit

Entry: Profile screen, bottom tab
Exit: Top-up, transaction detail, payment methods

UI Elements

  • Wallet balance display (prominent)
  • Recent transaction list
  • Top-up button
  • Payment methods button
  • Transaction filters: All, Credits, Debits
  • Empty state illustration

States

default loading empty error

Actions

Wallet balance tap - shows detailed breakdown
Transaction item tap - opens transaction detail
Top-up button - opens top-up amount selection
Payment methods - opens saved payment methods
Filter tabs - changes transaction list view

Data Shown

Current wallet balance (in BDT)
Recent transaction date and description
Transaction amount (+/-)
Transaction status (completed, pending, failed)
Payment method used for each transaction
