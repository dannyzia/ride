Rider Home Screen Wireframe

Purpose

Main screen for requesting rides, displaying current location and nearby activity

Entry / Exit

Entry: App launch, bottom tab navigation
Exit: Find Ride screen, Profile, Wallet, etc.

UI Elements

  • Map view showing current location
  • Search bar: "Where to?"
  • Current location indicator
  • Primary action button: "Set Pickup Location"
  • Quick access cards: Frequent destinations, Ride history
  • Bottom navigation: Home, Activity, Profile, Wallet

States

default loading empty error

Actions

Search bar - opens Find Ride screen
Current location button - centers map on user location
Set Pickup Location button - confirms pickup point
Quick access cards - navigate to respective screens
Bottom tab navigation - switches between app sections

Data Shown

User's current location (GPS)
Map tiles (MapLibre with Barikoi)
Frequent destinations (from user history)
Recent ride activity

User sets pickup and dropoff locations to request a ride

Exit: Ride confirmation screen or back to home

  • Two input fields: "Pickup location" and "Dropoff location"
  • Map view showing both locations
  • Primary button: "Request Ride"
  • Fare estimate display
  • Vehicle type selector
  • Reverse route button (swap pickup/dropoff)

States

default <loading error success

Actions

Pickup location input - opens autocomplete search
Dropoff location input - opens autocomplete search
Map interaction - adjust pin locations
Vehicle type selector - opens vehicle options modal
Reverse route button - swaps pickup and dropoff
Request Ride button - initiates ride request process

Data Shown

Pickup address (user selected or searched)
Dropoff address (user selected or searched)
Estimated fare and ETA
Selected vehicle type
Route preview on map
